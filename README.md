# 🧮 My Calculator

A simple calculator built using **HTML, CSS and JavaScript**.

🔗 **Live Demo:** https://preranad2006-max.github.io/CodeAlpha_my-calculator/

## ✨ Features
- Addition, Subtraction, Multiplication, Division
- Percentage and Decimal support
- Clear and Backspace
- Keyboard support
- Responsive design

## 🛠️ Technologies
- HTML5
- CSS3
- JavaScript
- GitHub Pages
